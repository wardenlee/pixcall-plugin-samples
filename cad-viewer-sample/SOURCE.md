# Corresponding source

This plugin distributes the GPL-covered LibreDWG parser as the following
Web Worker and WebAssembly assets:

- `dist/assets/libredwg-parser-worker.js`
- `dist/assets/libredwg-web.wasm`

The corresponding source for the versions used by this sample is available
from these upstream repositories:

- `@mlightcad/libredwg-converter@3.14.2`:
  <https://github.com/mlightcad/realdwg-web/tree/main/packages/libredwg-converter>
- `@mlightcad/libredwg-web@0.7.10`:
  <https://github.com/mlightcad/libredwg-web>
- LibreDWG:
  <https://github.com/LibreDWG/libredwg>

The plugin source and build configuration in this repository are also part of
the corresponding source for the combined plugin distribution.
